# 자투리여행 프로젝트 브리프

이 문서는 제안서 내용을 바탕으로 앱 개발의 큰 방향을 정리한 제품 기준 문서입니다. 세부 기능은 아직 확정하지 않고, 앞으로 화면/데이터/API/디자인을 결정할 때 흔들리지 않을 기준만 잡습니다.

## 한 줄 정의

자투리여행은 강원 자가용 여행 중 생기는 짧은 여유 시간을 현재 이동 경로 안에서 방문 가능한 관광 경험으로 바꿔주는 경로 기반 관광 큐레이션 앱입니다.

## 문제 의식

국내 여행은 자가용 이동과 당일·단기 여행 비중이 높습니다. 강원 여행에서도 고속도로 이동, 휴게소 정차, 숙소 체크인 전후 대기, 일정 조기 종료 같은 상황에서 짧은 여유 시간이 자주 생깁니다.

기존 관광 정보는 공식 데이터와 신뢰도는 높지만, 주로 사전 탐색형 자료나 개별 관광지 소개 형태로 제공됩니다. 그래서 실제 이동 중인 사용자가 현재 경로, 남은 시간, 날씨, 동반자, 접근성 조건에 맞춰 바로 쓰기 어렵습니다.

## 서비스 방향

자투리여행은 “어디가 유명한가”보다 “지금 이 경로와 시간 안에서 어디를 들르면 좋은가”에 집중합니다.

추천은 단순 주변 검색이 아니라 다음 조건을 함께 고려해야 합니다.

- 현재 위치 또는 이동 경로
- 최종 목적지
- 남은 자투리 시간
- 경로 이탈 부담
- 동반자 유형
- 날씨와 계절
- 영업시간
- 보행 난이도
- 주차와 접근성
- 공식 관광 데이터 신뢰도

## 핵심 사용자

- 수도권에서 강원으로 자가용 여행을 가는 사용자
- 당일치기 또는 1박 2일 단기 여행자
- 목적지는 정했지만 중간 경유지는 정하지 않은 사용자
- 가족, 커플, 친구, 혼자 운전하는 여행자
- 아이 동반, 고령자 동반, 휠체어 접근성 등 조건을 고려해야 하는 사용자

## 초기 지역 범위

초기 적용 지역은 강원특별자치도입니다.

우선 고려 동선은 다음과 같습니다.

- 영동고속도로
- 서울양양고속도로
- 강원 공식 드라이브 코스
- 강원 네이처로드 주요 코스

초기 추천 카테고리는 다음이 적합합니다.

- 경관 감상 포인트
- 짧은 산책 코스
- 휴게소 연계 정차 지점
- 자연·휴양형 관광지
- 공식 추천 여행지
- 접근성 좋은 관광지

## 제품 원칙

1. 경로를 크게 망치지 않아야 한다.
2. 남은 시간 안에 실제로 다녀올 수 있어야 한다.
3. 운전자 안전과 휴식을 방해하지 않아야 한다.
4. 공공 관광 데이터를 기반으로 신뢰 가능한 추천을 해야 한다.
5. 사용자가 비교하기 쉬운 선택지를 제공해야 한다.
6. 여행 계획을 완전히 다시 짜게 만들지 않아야 한다.
7. 목적지 중심 관광이 아니라 이동 과정의 경험을 확장해야 한다.

## 추천의 기본 형태

추천 결과는 개별 장소 나열보다 비교 가능한 묶음 카드가 어울립니다.

예시:

- 전망 포인트 1곳 + 짧은 산책 1곳
- 휴게소 정차 + 근처 관광지 1곳
- 카페 1곳 + 경관 감상 포인트 1곳
- 아이 동반 가능 장소 1곳 + 짧은 체류 코스
- 비 오는 날 실내/저보행 장소 1곳

각 추천 카드는 사용자가 빠르게 판단할 수 있도록 다음 정보를 가져야 합니다.

- 예상 추가 소요 시간
- 목적지 대비 경로 이탈 정도
- 추천 이유
- 체류 예상 시간
- 운영 여부
- 주차/접근성 정보
- 날씨 영향
- 외부 내비게이션으로 이동 버튼

## 데이터 방향

한국관광공사 TourAPI는 관광지 정보의 Master Data로 사용합니다.

활용 후보 데이터:

- 국문 관광정보 서비스
- 무장애 여행 정보
- 기초지자체 중심 관광지 정보
- 관광지별 연관 관광지 정보
- 관광빅데이터 정보서비스

앱 내부에서는 관광지명, 주소, 좌표, 분류, 대표 이미지, 소개 문구, 운영 정보, 접근성 정보 등을 표준화해 사용합니다. 이후 기상, 교통, 휴게소, 도로망 같은 문맥 데이터를 결합해 추천 품질을 높입니다.

## 아직 확정하지 않을 것

다음은 지금 단계에서 바로 고정하지 않습니다.

- 정확한 추천 알고리즘
- 로그인 필요 여부
- 서버 구조
- 지도 SDK
- 실시간 위치 추적 범위
- 결제/예약 기능
- 리뷰/커뮤니티 기능
- 운영자 관리 도구의 상세 기능

## 성공 기준

초기 버전의 성공 기준은 “사용자가 강원으로 이동 중 30분에서 2시간 정도의 여유 시간을 입력했을 때, 실제로 들를 만한 후보를 이해 가능한 이유와 함께 받을 수 있는가”입니다.
